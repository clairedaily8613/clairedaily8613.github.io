這兩週過得還好嗎？

注意身體健康啊！

前兩週我基本上都在感冒，根本沒辦法做事。大概到上週四才稍微好一點，在那之前就是咳嗽超嚴重，鼻涕跟痰還出現血絲，真的有嚇到我。雖然沒有量體溫，但整個人一直有種低燒的感覺。

總之就是完全不知道自己在幹嘛，身體跟腦袋都要死不活。


病終於好一點以後，我開始嘗試玩 Linux 系列的作業系統。

目前選了 Fedora 跟 Ubuntu 來測試。玩下來我覺得 Fedora 的畫面操作沒有 Ubuntu 順，可能因為我太習慣 Win11，所以沒有 Dock 的時候就覺得很不順手。實際使用感兩邊其實差不多，差比較多的是下載安裝檔時用的格式不同。

Linux 現在雖然有通用的 AppImage，但我目前感覺還是直接下載安裝檔比較好，安裝起來也比較簡單。對 Ubuntu 來說，下載安裝檔比 AppImage 快；但 Fedora 對 AppImage 的支援度好像又高不少。

我其實比較喜歡 Fedora，可是實際上手速度還是 Ubuntu 快很多。

順便說一下，Ubuntu 在中文輸入法的安裝上比 Fedora 困難很多。Fedora 的中文輸入原生就有很多選擇，但我不確定是不是因為安裝的時候 Fedora 有連網、Ubuntu 沒有連網，所以才會差這麼多。

現在比較認真在想的是，以後我要怎麼配置自己的電腦系統。主系統應該會轉去 Ubuntu 吧，但 Win11 還是會保留。沒辦法，誰叫 Claude cowork 根本不能在 Linux 上跑。

可惡，我還沒去拿我的新 Mac。我明明很期待，但要等月底才有時間去拿。


上週四還去了 AI Camp 的活動，在 Google London 的辦公室。

那個辦公室真的超美，地點就在 Kingcross Underground 附近，走路大概五分鐘就會到。整個環境我其實聽得很開心，讓我困惑的是剛進門差點以為自己在臺北，因為一堆臺灣人哈哈哈。

只是最近在外面一聽到中文就覺得頭痛，不是很想在家裡以外的地方說中文。

這次活動大概分成三個 Sponsor。第一個當然是 Google，內容是用 Google 一系列 AI 產品協作完成一個 Side Project。第二個是一個 AI Agent 的 Agent 互動平台，跟之前看到的龍蝦社群有點像，就是大家的 Agent 可以一起玩。第三個是租借算力的平台，讓你連到他們伺服器上的開源 LLM，然後用收租的形式收費。

第一個我覺得就是大家把 YouTube 打開，其實有一堆教學。第二個感覺滿好玩的，但對我來說，把一個 AI Agent 卡在電腦裡好像有點怪。不過自己搞一個本機 Agent 好像又滿有趣，我正在想可以怎麼下手。

至於第三個租算力，如果大家沒有隱私問題的話，Open Router 這個網站其實可以免費用各種 LLM。以我個人的資料安全考量，不是很推薦啦。但如果只是學生想做作業之類的，應該沒有什麼太嚴重的隱私問題，這部分應該會是個滿好用的工具。


除了電腦系統跟 AI 活動，這兩週我也開始在廚房做實驗。

做了麵粉煎、大阪燒、法式吐司。麵粉煎沒有花生糖粉，所以我直接用 100% 花生醬；大阪燒失敗；法式吐司倒是比較正常一點。

反正就是為了吃，開始做各種奇奇怪怪的實驗。

在英國出門吃飯總是會讓我很懷疑人生。不確定是不是我自己要求太高，但英國的食物我真的吃不懂。有夠難以理解的貴，之前吃到一個小漢堡要 13 磅，雖然小小的但吃完超級飽，走出去的時候有點想昏倒。

明明很小一個啊啊啊！

這邊的咖啡豆也讓我滿絕望的，到後面甚至有點不想喝咖啡。英國這邊的咖啡豆烘焙程度比臺灣深很多，對我這種習慣淺焙的人來說真的很難入口。

以前在臺灣用加壓摩卡壺覺得剛好，來了以後直接放棄加壓。還好我當初帶摩卡壺的時候一次帶了兩個版本，不然這邊的咖啡豆用加壓的，總覺得一直有一種燒焦味，實在很難喝。


這兩週好像都在重新適應。

身體從感冒裡慢慢爬回來，電腦系統也開始重新想怎麼配置，生活上則是在英國的外食和咖啡之間，努力找出一點自己能接受的方式。

雖然大部分時候都還是在邊試邊撞牆，但至少開始有一點回到自己的節奏了。

你最近有沒有也在重新配置生活裡的某個部分？
