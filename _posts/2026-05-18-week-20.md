上週過得好嗎？

上週的我，一邊在廚房做新食物，一邊在換筆電的作業系統。

我最近很想把生活裡那些一直卡住、一直讓人煩躁的東西，慢慢換成比較順手的版本。


先說電腦。

我的 Win11 只要幾天不關機，重開機的時候就很常出事。桌面、桌布之類的設定全部跑掉，應用程式全部找不到，最糟糕的是有時候會直接無法登入，要再重開機一次才進得去。

一開始我還不覺得這是什麼大問題，想說電腦嘛，偶爾鬧一下也很正常。但後來每次開機都出問題，我就開始覺得不行，這東西真的很煩。

所以我開始把不同作業系統灌在外接硬碟裡，長時間使用看看自己能不能適應。

目前測了兩個 Linux：Ubuntu 跟 Fedora。

我的使用時間還不算很長，所以其實沒有覺得兩者差很多。以從 Win11 跳過去的直覺性來說，Ubuntu 的上手速度比 Fedora 快。最大的差異大概在桌面介面跟安裝方式，Ubuntu 預設有 Dock，Fedora 要自己裝插件。其他就是安裝檔、指令、套件格式有一點差異。

但說實話，現在使用 Linux 已經沒有以前那麼可怕了。

自從有 AI 以後，查 Linux 指令已經不再是很大的麻煩。我有問題就是問 GPT，然後複製貼上，基本上沒有什麼太大的難度。使用起來也沒有什麼卡頓。

甚至用下來，我沒有覺得 Win11 有什麼非用不可的情境。

稍微可惜的是 Notion、Claude、ChatGPT、Line 這些常用工具沒有 Linux 原生桌面版，但網頁端還是可以用，所以也不算大問題。不能嘗試 Claude Cowork 是有點可惜，不過還是可以用 Claude Code 的 CLI。說實話，我不覺得這是什麼很嚴重的阻礙。

目前用下來我滿滿意的。

而且 Linux 的 Disk 工具甚至比 Windows 好用很多。我可以不用第三方工具，就直接把隨身碟或硬碟格式化成我想要的格式，讓它可以在 Mac、Linux、Win11 之間通用。

如果你手上剛好有沒在用的 PC，我真的覺得可以玩玩看 Linux。反正不用錢，甚至還有可能讓舊機復活。

很多人推 Mint，據說是最輕量、最友善的版本，但我這次還是選了自己比較習慣、也比較好奇的 Ubuntu 跟 Fedora，就沒有再去玩 Mint 了。


重裝系統這件事，讓我有點夢回還在學校的時候。

那時候為了跑上課的 Spark 跟 Hadoop，硬是在筆電裡裝了 Ubuntu。當時我對 Linux 的印象只有難用，所有 bug 都要上 Google 查，一個一個網頁翻，一個一個方法試，看看有沒有用。

最後的結局就是，我對 Linux 有一定的心理陰影。

除了因為跑在模擬器裡速度超慢以外，要查的資料又多到讓人發瘋。那時候也常常覺得自己不知道到底裝壞了什麼，只好一直重裝。

我甚至為了裝輸入法就搞了一個小時。

還有一個我裝 Ubuntu 的慘痛經驗是：不要一開始就裝中文版。

裝中文版會讓整個電腦的路徑變成中文。我記得這件事會讓 Terminal 變得神級難用，後來才知道還是裝英文版比較輕鬆。

以前的我大概會覺得 Linux 是一種修行，但現在再回去看，感覺它變成一個可以選擇的生活工具了。

這個差距其實滿奇妙的。


除了電腦系統，我最近也在重新調整吃飯這件事。

在英國的飲食幾乎都是自己煮，目前我還不太想繼續出門踩雷。

每次出去吃完都覺得有夠問號：這個東西值得這個價格嗎？又不好吃，也不是什麼很稀有的東西，有時候甚至很像現成食品。英國的 Chinese Takeaway 就是一堆這種東西。

年初的時候去吃過幾次，吃完就開始懷疑人生，也給我帶來很嚴重的心理陰影。現在對出門吃飯這件事有很多負面想法。

唯一一次我覺得吃了不生氣，是之前去買咖啡豆順便吃午餐。那次吃到的漢堡不難吃，可惜的是我回家以後就發現，外食對我的身體負擔實在很大。

我覺得我大概只能吃超市 meal deal 的三明治了。外面煮得比較精緻的東西，對我來說反而有點太負擔。

所以最近在家實驗了新的食物：自己調涼麵的麻醬，還有用微波爐做蒸雞。

我現在覺得，如果不想洗鍋子，真的應該多學學微波爐的一百種用法。

微波爐真的是偉大的發明。

不用把自己搞得很狼狽，東西丟進去，設定時間，等它完成就好了。比起直火煮東西，直接丟微波爐還比較快，沒有油煙，也不用洗一堆鍋碗瓢盆。

多麼快樂的食物啊。


還有一件最近讓我覺得生活變簡單的事：我開始訂閱超市外送了。

以後不用自己跑超市，扛一堆東西回家了。

唯一比較煩的是 25 磅起送，但平常生鮮有點難卡到 25 磅，所以常常都是壓線訂。也因為有了超市外送，我又少了一個出門的理由。

沒事真的會不想出門呢。

倫敦最近晚上大概都是 8 到 13 度，白天比較溫暖的時候多半是 20 度上下。這根本就是臺灣的冬天啊。

但我竟然也開始可以只穿一件外套，在 12 度的天氣出門。

這讓我對人類的適應能力有新的認識。以前 12 度的時候，我大概已經把自己包成粽子了吧。


所以這週好像是在把生活換成比較不會卡住的版本。

電腦不要每次開機都出事，吃飯不要每次外食都懷疑人生，買菜不要每次都扛到手快斷掉。

這些都不是什麼很大的改變，但加起來會讓日子變得比較少一點摩擦。

我最近很需要這種東西。

你呢？上週還好嗎？

有沒有什麼最近也想換成比較順手版本的東西？

或是你對英國的生活有什麼好奇的，也可以跟我說。
