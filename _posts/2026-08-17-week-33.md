上週過得如何？

上週因為一些原因，我家突然就只剩我一個人了。另外還遇到了日蝕跟流星雨，然後把我的網站從 Github Page 搬去了 Cloudflare。

---

先說一個人住這件事。

因為空間很大，有時候真的有點迷茫。不確定是不是以前從來沒有遇過自己住在一個超大的空間，導致我其實會莫名有點不安。

但實際上又很開心，因為我幾乎沒有獨自住在一間公寓或房子的經驗。所以我自己確定了一件事，我其實很喜歡獨居。

---

再來說日蝕。

上週三還是日蝕跟流星雨。倫敦上週的天氣極好，幾乎沒有什麼雲，所以日蝕的部分我有看到，還拍了照。可惜的是流星雨，精神上實在是撐不太住，就去睡覺了。

我記得我上次看到日蝕的時候還在花蓮，印象中好像是大學快畢業的時候？想不到來到英國還能遇到日蝕呢！

流星雨的部分我到現在還是沒有親眼看到，但有看到有人在飛機上拍到流星雨，超級漂亮的！我的運氣真的很好呢！

---

最後說網站。

上週還做了一件事，就是把我的網站從 Github Page 轉去放在 Cloudflare，也同時把網頁的網址稍微修改了一下。

我的網站是一個靜態的網頁，沒有很炫炮的動畫、很漂亮的 UI 設計，我本身並沒有學過這些，基本上就是 AI 生的，我直接拿來用並且直接調整。

網址的部分我想吐槽一下，就是原來 Github Page 用的 DNS 設定跟 Cloudflare 差別有點大欸。Cloudflare 只要一個就夠了，Github Page 的設定要好幾個參數。

重新設定比我想像中的簡單。

最近越來越多事情就是拖很久，然後發現其實比我想像中的簡單，果然還是要多行動啊。

歡迎你跟我分享你的新鮮事！
